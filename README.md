# Smart Home Automation & Security System (Tinkercad Simulation)

An Arduino-based multi-functional Smart Home Automation and Safety System simulated on Tinkercad. This project demonstrates real-time sensing and automated control for modern smart houses.

## 🚀 Key Features Demonstrated in Simulations:
1. **Motion Detection:** PIR Sensor triggers system responses upon detecting human presence.
2. **Automatic Light Control:** LDR (Photoresistor) controls light bulbs via Relay modules based on ambient light levels.
3. **Proximity & Door Automation:** Ultrasonic Distance Sensor detects approaching objects to trigger Servo Motor action (Automatic Door/Gate).
4. **Gas & Fire Safety:** Gas Sensor detects smoke/gas leaks and activates the Piezo Buzzer alarm instantly.

## 🛠️ Components Used:
* Arduino Uno R3
* PIR Motion Sensor
* LDR (Photoresistor)
* Ultrasonic Distance Sensor (HC-SR04)
* MQ Gas Sensor
* Relays & Light Bulbs
* Servo Motor
* Piezo Buzzer
* DC Motor & Power Supply
